# 第2回　サンプリングの理論

社会調査と観測・実験の違いを確認したうえで、全数調査と標本調査、標本誤差と非標本誤差、無作為抽出と有意抽出法・割当法の違いを説明します。標本誤差の計算と必要標本数の考え方、1936年アメリカ大統領選挙の予測の失敗も扱います。末尾にその日の課題を収録しています。
