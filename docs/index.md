*Social Research Methods 2*

立教大学で2022年度に担当した授業の資料です。ここに置いているのは主に **2022年度** の版です。

!!! info "過去の授業の記録です"
    この授業は現在は開講していません。成績評価や試験に関するページ、一部の図版は、公開にあたって省いています。

## この授業について

社会調査の設計と実施方法を、質的調査法と量的調査法に分けて学ぶ授業です。3名の教員が分担して担当し、このサイトには小野原が担当した量的調査法の回（サンプリングの理論と方法、調査票調査の実施、調査データの整理）の資料を掲載しています。教科書は盛山和夫『社会調査法入門』（有斐閣）です。

| | |
|---|---|
| **大学** | 立教大学 |
| **開講** | 社会学部（科目コード DK017） ／ 秋学期 |
| **担当年度** | 2022年度 |

回の番号と順序は、シラバスの授業計画ではなく実際の開講順（ガイダンス資料の日程表）に合わせています。第6〜13回は他の教員の担当回のため資料はありません。各回のスライド末尾にはその日の課題（小テスト）があり、解答は別ファイルです。
